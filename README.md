# AlicaConnector

Плагин Lampa для голосового управления через навык Алисы «Лампа ТВ». Держит
WebSocket-соединение с `lampa-alice-server` и выполняет команды через API
Lampa. Описание проекта: `../PROJECT.md`.

Сверено с исходниками Lampa 3.3.7 (`yumata/lampa-source`).

## Установка на ТВ

1. Lampa -> Настройки -> Расширения -> добавить плагин:
   `https://toyotasx.github.io/alica-connector/alica-connector.js`
2. Настройки -> AlicaConnector:
   - «Адрес сервера» - домен VPS (например, `lampa.example.com`; `wss://` и `/ws`
     подставятся сами). Если при сборке задан `ALICA_SERVER`, поле уже заполнено.
   - «Код привязки» - `PAIR_CODE` из `.env` сервера. Вводится один раз: сервер
     выдаёт токен, плагин хранит его в `Lampa.Storage`, код не сохраняется.
3. Статус должен смениться на «Подключено».
4. «Отвязать телевизор» стирает токен на ТВ; на сервере запись остаётся, её
   удаляют вручную (README сервера).

Lampa загружает плагин при каждом старте, поэтому обновление на ТВ -
перезапуск Lampa (GitHub Pages кэширует файл до 10 минут). Версия видна в
статусе настроек и в логе сервера (`online ... plugin=...`).

## Действия

| action | Что делает |
|---|---|
| `open_card` | поиск через TMDB-источник Lampa (`Lampa.Api.search`), выбор лучшего совпадения (название, год из фразы, известность), открытие `full` через `Lampa.Router` |
| `torrents` | находит карточку и открывает штатный экран `torrents`; раздачи ищет парсер из настроек Lampa |
| `play` | открывает штатный экран торрентов и нажимает раздачу, как OK на пульте: последнюю запущенную, а если её нет - верхнюю в списке. `{recommended: true}` - последний совет `recommend` |
| `recommend` | советует фильм или сериал по истории просмотров (параметры `kind`, `genre`) и открывает карточку |

Как `play` выбирает раздачу (`src/actions/play.ts`, `quality.ts`):

- список, сортировка и фильтр - те, что выбраны на экране торрентов в Lampa;
- плагин ждёт, пока экран отрисует раздачи (событие `Lampa.Listener` `torrent` /
  `render`), не дольше `parse_timeout` + 8 секунд;
- последняя запущенная раздача определяется по хэшам в `torrents_view` (их
  Lampa хранит в порядке запуска и показывает значком «просмотрено»);
- если список пуст (jac.red не успел ответить), экран перезагружается один
  раз; если пусто снова - `no_torrents`, экран остаётся открытым;
- нажатие - штатное `hover:enter` по раздаче: дальше TorrServer, список
  файлов и плеер Lampa (история и таймкоды работают).

После нажатия раздачи плагин ждёт список «Файлы» (событие `torrent_file` /
`render`, до 90 секунд, пока TorrServer грузит метаданные) и выбирает файл
(`src/actions/episode.ts`):

- один файл (фильм) - запускается сразу, без 10-секундного отсчёта Lampa;
- сериал - последняя серия с прогрессом (`timeline.percent`), если досмотрена
  меньше чем на 90%, иначе следующая; если ничего не смотрели - первая серия;
  если досмотрена финальная серия - выбор за человеком;
- несколько файлов без номеров серий - выбор за человеком.

Как `recommend` подбирает (`src/actions/recommend.ts`, `taste.ts`, `genres.ts`):

- затравки - последние карточки истории (`Lampa.Favorite` `history`), лайки и
  закладки;
- пул - рекомендации TMDB к каждой затравке (`Lampa.Api.sources.tmdb.get`),
  собирается в фоне (через 30 с после старта, после пополнения истории, старше
  12 часов - заново) и лежит в `Storage` `alica_rec_pool`: сервер ждёт ответ
  2 секунды, а запросов десяток;
- отсев просмотренного, брошенного, лайкнутого, советованного за 14 дней
  (`alica_rec_recent`), малоизвестного (меньше 50 голосов) и без постера;
- оценка: совпадения между затравками, сглаженный рейтинг, известность,
  близость к жанрам вкуса; выбор - случайный из 8 лучших;
- мало подходящих (жанр, сериал, пустая история) - добор `discover` по жанру
  или `trending`, не дольше 1,5 с;
- последний совет - в `alica_rec_last` (для «включай»).

Торренты должны быть включены в Lampa (плагин `etor`, парсер в настройках).
Для `play` нужен TorrServer в настройках Lampa; на Android - торрент-клиент.

Список действий отправляется серверу в `hello`, поэтому на ещё не
реализованное действие Алиса отвечает «Обновите плагин».

## Структура

```
src/
  index.ts        старт после app:ready, связывает всё вместе
  settings.ts     раздел настроек: статус, адрес, код, «Отвязать»
  socket.ts       WebSocket: pair/hello, команды, ping каждые 25 с,
                  переподключение 1-60 с, обнаружение «повисшего» соединения
  protocol.ts     типы протокола, нормализация адреса сервера
  lampa/          единственное место, где вызывается API Lampa
    types.ts      используемая часть window.Lampa (всё необязательное)
    index.ts      поиск, карточка, экран торрентов, события, нажатия
  actions/        действия и реестр
    open_card.ts, torrents.ts, play.ts, recommend.ts
    find.ts       поиск карточки по фразе (общий для всех действий)
    match.ts      выбор фильма из результатов TMDB
    quality.ts    выбор раздачи (последняя запущенная или верхняя), качество
    episode.ts    выбор файла: фильм или нужная серия
    taste.ts      алгоритм совета: затравки, профиль жанров, оценка, выбор
    genres.ts     ключи жанров сервера -> id TMDB, русские названия
tests/            vitest с фейковым window.Lampa
```

## Разработка

```bash
npm ci
npm test
npm run typecheck
npm run build
```

Сборка: `dist/alica-connector.js`, один IIFE-файл, `target: chrome56`
(Tizen 4). Для другого движка: `ALICA_TARGET=chrome47 npm run build`.

Чего нельзя в коде (Chromium 56 на ТВ упадёт целиком или функция не сработает):

- регулярки с `\p{...}` (Chrome 64+); `\b` не работает с кириллицей - русские
  слова проверять без `\b`;
- `Promise.prototype.finally`, `Array.prototype.flat`, `Array.prototype.at`;
- синтаксис esbuild понижает сам (`?.`, `??`, `catch {}`, spread).

После сборки полезно проверить: `node --check dist/alica-connector.js`.

Проверка в настоящей Lampa без ТВ: веб-версия `http://lampa.mx` (Chrome
переводит её на HTTPS и не открывает, поэтому её удобно отдавать через
локальный прокси на `127.0.0.1`) + плагин через
`Lampa.Utils.putScriptAsync([url])` в консоли + локальный сервер. Торренты
включаются как в `etor`: `lampa_settings.torrents_use = true`, парсер
`jackett` с адресом `jac.red`. TorrServer в браузере нет, поэтому
`Lampa.Torrent.start` для проверки подменяют перехватом.

API Lampa неофициальное. При обновлении Lampa сверять используемые вызовы с
исходниками `yumata/lampa-source` нужной версии: `Api.search`, `Router.call`,
`Activity.push/replace/active`, `SettingsApi`, `Listener` (`app`, `torrent`,
`torrent_file`), `Storage` (`torrents_view`, `parse_lang`, `parse_timeout`,
`parser_use`), `Torserver.url`, `Favorite.get/listener`,
`Api.sources.tmdb.get`.

## Публикация

GitHub Actions (`.github/workflows/pages.yml`) на каждый пуш в `main`
проверяет типы, гоняет тесты, собирает и выкладывает `dist/` на GitHub Pages.
В репозитории: Settings -> Pages -> Source: GitHub Actions. Адрес сервера по
умолчанию задаётся переменной `ALICA_SERVER` (Settings -> Secrets and
variables -> Actions -> Variables).
